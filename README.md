# Python Data Analysis Notebooks: NumPy, Pandas, Matplotlib & Seaborn

A growing collection of classroom-style Jupyter notebooks for learning the
core Python libraries for data analysis and visualization from scratch.
Each topic is explained in simple language, followed by runnable code with
comments on what every line does.

## 🗺️ Suggested Learning Order

1. **NumPy** – numerical computing and arrays
2. **Pandas** – working with tabular data
3. **Matplotlib** – creating basic and custom charts
4. **Seaborn** – statistical visualization on top of Matplotlib and Pandas

## 🔢 NumPy Notebook: Topics Covered

- Creating arrays (scalars, vectors, matrices, tensors)
- Array properties, mathematical operations
- Indexing, slicing and selection
- Broadcasting, views and copies
- Reshaping, stacking, combining and set operations
- Missing values, sorting, searching and comparing
- Load, save and printing options
- Vector and matrix operations, linear algebra
- Tensors and solving linear equations

## 🐼 Pandas Notebook: Topics Covered

- Series and DataFrame basics
- Reading CSV files and understanding a dataset
- Selecting data with `loc`, `iloc`, `at`, `iat`
- Filtering and sorting
- Missing values, data types, dates, duplicates, text cleaning
- Adding, renaming, updating and deleting columns
- `map()`, `replace()`, `apply()`
- GroupBy, pivot tables and crosstabs
- Concatenation, merge (SQL-style joins) and `join()`
- Exporting data and practice questions

## 📊 Matplotlib & Seaborn *(coming soon)*

- Line, bar, scatter, histogram and pie charts
- Customizing titles, labels, legends, colors and styles
- Subplots and figure layouts
- Seaborn statistical plots (distribution, relational, categorical)
- Heatmaps and correlation plots
- Visualizing Pandas DataFrames

## ✨ Features
